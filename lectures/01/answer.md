## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：一般的な知識から推測した回答。「～を意味していると考えられます。」
- 用語集の正しい意味と比べて気づいたこと：ある程度的を射たことを言ってくれているが、データベースを参照した完全に意図通りの回答ではない
- 表示できたトークン数（入力 / 出力）：7 / 635

## 宿題

- 取り組んだレベル：実装
- やったこと：`app/ask.py` に `--interactive`（`-i`）を追加し、質問と回答を会話履歴として次の質問時にもGeminiへ送るようにした。`uv run python -m app.ask --interactive` で開始し、`/exit` または Ctrl+C で終了できる。既存の単発質問とトークン数表示も維持した。
- 結果：続けて質問すると、それまでの質問・回答がモデルに渡される。自動テストで、2回目のリクエストに1回目の質問と回答が含まれることを確認した。
- 気づき・疑問：会話が長くなるほど履歴も大きくなるため、入力トークン数が増える。長い会話ではトークン数や利用量に注意が必要。
